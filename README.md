Atualizações oficiais do IKA Gaming Launcher

## Atualizações do servidor

### Mestre das Habilidades IKA — v1.0

NPC **919600**, com **33 lições** para desbloquear habilidades de classe no CMaNGOS TBC 2.4.3. Inclui instalação SQL, conferência, remoção e documentação.

A instalação no MariaDB foi concluída sem erros; o responsável pelo servidor confirmou funcionamento em todas as classes.

Consulte o [pacote e as instruções](server-updates/mestre-habilidades/v1.0/README.md). A aplicação é administrativa, no banco do servidor. O launcher não precisa distribuir esses arquivos aos jogadores.
